# 102 Patches: Detours to the Rescue! (DttR)

DttR is a modern launcher and runtime for **102 Dalmatians: Puppies to the Rescue** on PC. It keeps the original game logic, replaces the fragile old Windows support code, and uses safer defaults on modern systems.

Read the docs: <https://dogstuff.gitlab.io/detours-to-the-rescue/>
