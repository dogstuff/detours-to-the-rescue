# 102 Patches: Detours to the Rescue! (DttR)

DttR is a launcher and runtime for the PC version of *102 Dalmatians: Puppies to the Rescue*. It helps the game run on modern systems and includes a modding SDK for creating and installing mods.

Read the docs: <https://dogstuff.gitlab.io/detours-to-the-rescue/>
